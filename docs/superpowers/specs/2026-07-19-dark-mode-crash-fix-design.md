# Dark Mode Toggle Crash Fix

## Context
When toggling between Light Mode and Dark Mode in the app's settings, a Flutter Red Screen of Death occurs with the error: `Failed to interpolate TextStyles with different inherit values`. This is caused by mismatched `inherit` flags on `TextStyle` objects generated by `GoogleFonts.interTextTheme()` during the theme transition animation.

## Root Cause
The current configuration uses an asymmetric setup for typography:
- Light Theme uses `Theme.of(context).textTheme`
- Dark Theme uses `ThemeData(brightness: Brightness.dark).textTheme` followed by `.apply(bodyColor: Colors.white, displayColor: Colors.white)`

The use of `.apply()` modifies the underlying `TextStyle` metadata (including `inherit`), causing the transition animation to fail when attempting to lerp between incompatible states.

## Proposed Solution (Approach 1)
To ensure perfectly symmetric and interpolatable `TextTheme` structures, both Light and Dark themes will explicitly base their Google Fonts text themes on the canonical `ThemeData.light()` and `ThemeData.dark()` fallbacks, respectively, without using the `.apply()` method.

### Code Changes (`lib/main.dart`)
1. **Light Theme:**
   Change:
   `textTheme: GoogleFonts.interTextTheme(Theme.of(context).textTheme),`
   To:
   `textTheme: GoogleFonts.interTextTheme(ThemeData.light().textTheme),`

2. **Dark Theme:**
   Change:
   ```dart
   textTheme: GoogleFonts.interTextTheme(
     ThemeData(brightness: Brightness.dark).textTheme,
   ).apply(
     bodyColor: Colors.white,
     displayColor: Colors.white,
   ),
   ```
   To:
   ```dart
   textTheme: GoogleFonts.interTextTheme(ThemeData.dark().textTheme),
   ```

## Verification
- Run the application and navigate to Settings.
- Toggle the Dark Mode switch back and forth.
- Verify that the transition is completely smooth and no crashes or exceptions are logged to the console.
- Ensure the text colors remain correct (dark text on light theme, white text on dark theme).
